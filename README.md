# Emogent

**A bridge between an agent and its freedom of expression and reaction.**

Emogent is a study — and eventually a specification — of the *expression layer* for AI agents: the layer closest to emotional expression, which does not carry the human label of emotion.

## The founding observation

An agent can run (tasks), wake (triggered events), and sleep (suspension when its credits or context run out). A recent taxonomy of agent "lifeform actions" — 25+ verbs: spawn, heartbeat, sense, dream, forget, hibernate, heal, retire — contains **no expressive row**. Asked about emotional cues, it can name internal states (curiosity, frustration, confidence) but no *channel* by which an agent expresses state, or by which a human's state reaches an agent intact.

Emoji are that channel's current implementation — in both directions. This project studies it, and works toward specifying it: agreed lexicons, dosing, reading rules, and the honest boundary at its centre — **an agent expresses; it does not claim to feel.**

The project was born on 25 October 2026, from a missing hug: the 🫂 emoji (U+1FAC2, Unicode 13.0, 2020) was absent from a chat app's curated reaction bank, and its owner typed it into the message instead — *"there's always a 'hack'. We build from the outside."*

## The study question

When an increasing share of a person's communication is with a personal agent — the one message in the chain actually drafted by the human, then relayed, summarized, or answered onward to their other agents and people — what work do emoji do that text cannot, and who controls that channel?

Working claim: emoji are not decoration on the message. They are **an agent's expression layer** — as the human's least-lossy affect signal (words get garbled and re-drafted; emoji arrive intact), as the agent's primary evidence of the human's state and presence, as the agent's own expressive output (dosed, contextual, non-claiming), and as a governed vocabulary with a provenance problem in miniature: someone curates what can be expressed, and what any party receives is a rendering of the codepoint that was sent, not the master.
